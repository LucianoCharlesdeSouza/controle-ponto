# controle-ponto


Gestão de Inativos/Exclusão:
Atualmente, no cadastro de colaboradores, todos ficam como "ativo". Poderíamos adicionar um botão para Desativar um colaborador que foi demitido (para ele não aparecer mais na tela de ponto, mas manter o histórico dele nos relatórios).

Relatório de Inconsistências:
Na tela de Relatórios, quando aparece o ícone de "⚠️", você não consegue ver qual foi o erro (ex: período em aberto). Poderíamos clicar nele para abrir um aviso explicando o que aconteceu.

Filtro de Motivos:
Se o sistema tiver muitos botões na tela de ponto, poderíamos dar a opção de ocultar/arquivar motivos que não são mais usados.

Criação Rápida de Motivo na Tela de Ponto:
Na especificação original, você mencionou que se o funcionário digitar um motivo novo, ele vira um botão. Podemos criar um botão de "+" na tela de ponto para cadastrar um motivo novo direto ali.

Lembrete de Backup: Um aviso na tela inicial (Dashboard) se o último backup foi feito há mais de 7 dias (para evitar que você perca dados por esquecimento).

Exportar Relatório em CSV/Excel: Para o relatório anual, gerar um arquivo que possa ser aberto no Excel (além do PDF).

Criação Rápida de Motivo na Tela de Ponto: Conforme a especificação original, um botão de "+" na tela de bater ponto para criar um motivo na hora, sem precisar ir nas configurações.

Dashboard Inicial: A tela de Ponto hoje é focada no colaborador. Poderíamos fazer a primeira tela mostrar um resumo do dia (quem já bateu ponto, quem está trabalhando agora, quem esqueceu de bater a saída).

Avisos na Dashboard: Um card de alerta se alguém esqueceu de bater a saída no dia anterior.

Geolocalização (GPS): Registrar a localização no momento do ponto (útil para auditoria).

Limpeza de Logs Antigos: Como você falou de períodos, talvez uma ferramenta para "arquivar/excluir" apenas marcações de anos passados.
